# Sunshard Saga

An original 3D story adventure that runs in the browser. Platform across floating isles, fight with a glaive that returns to your hand, learn Fire, and face the Hollow King in a turn-based boss battle.

**Play:** https://raphaelprahtamaid-source.github.io/sunshard-saga/

## Controls

| Keyboard / mouse | Phone |
| --- | --- |
| WASD move, Space jump (twice to double jump) | Left thumb joystick, Jump button |
| J or click: strike, K or right-click: throw glaive | Strike / Throw buttons |
| L: Fire (after the Flame Shrine), H: potion | Fire / Potion buttons |
| E: talk, drag or arrow keys: camera | Tap the prompt to talk, drag right side to look |

Battle menu: arrow keys + Enter, or tap the commands.

Built with [three.js](https://threejs.org/) r128 in a single `index.html`.
